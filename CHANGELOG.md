# 1.2.2 — Fabric ports

- Add Fabric builds for Minecraft 1.20.1, 1.21.1, and 26.1.2.
- Preserve the fountain multiblock, 44 built-in wishes, biome and structure searches, weather wishes, custom item wishes, three fountain appearances, advancements, and boss drops.
- Add Fabric registration, lifecycle, loot, configuration, and client renderer integrations.
- Retain opaque fountain rendering and off-screen rendering for the large multiblock model.
- Synchronize custom recipes on 26.1.2 when joining a server and after data pack reloads, and refresh JEI when the recipes arrive.
- Use the matching recipe ingredient format and item model resources for each Minecraft version.
- Process fountain item transfers on the server and preserve item components during storage.

Requires Fabric API. JEI is optional. Compiled and packaged without launching Minecraft.
